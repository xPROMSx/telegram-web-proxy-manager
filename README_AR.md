**Telegram Web Proxy Manager (TWPM)** مدير مجاني لتثبيت بروكسي Telegram WEB خاص بك على خادم VPS وصيانته. يستخدم [Telemt](https://github.com/telemt/telemt) كمحرك للبروكسي، ويعتمد على Nginx لتوفير HTTPS وتوجيه الاتصالات حسب النطاق وعرض موقع التمويه. يضبط المدير المكوّنات اللازمة، ويستخرج شهادة Let's Encrypt، ويعرض رابطًا جاهزًا لإضافة البروكسي إلى Telegram.

**أكثر من مجرد مُثبّت لـ Telemt:** تحصل كل عملية تثبيت جديدة على موقع أصلي متعدد الصفحات بتصميم مخصّص. يُستخدم Nginx الموجود بالفعل بدلًا من خادم ويب إضافي، مع إدارة البروكسي والشهادات والموقع ضمن تثبيت واحد.

يُطوَّر **TWPM** و[**3X-UI AUTO NGINX**](https://github.com/xPROMSx/3x-ui-auto-nginx) كمشروعين تابعين لـ xPROMSx مع مراعاة العمل المشترك. يمكن تشغيلهما على خادم VPS واحد ومشاركة Nginx مع استقلال إعدادات كل مشروع وشهاداته وخدماته. **يدعم TWPM أيضًا إعدادات Nginx المتوافقة الأخرى**؛ تثبيت 3X-UI ليس إلزاميًا.

## 🚀 البدء السريع

تحتاج إلى **VPS يعمل بنظام Ubuntu 24.04 أو 26.04**، وصلاحيات **root**، وخادم Nginx يعمل بإعداد SNI مدعوم، و**نطاق أو نطاق فرعي مستقل**. يجب أن يشير سجل DNS من النوع A إلى عنوان IPv4 العام لخادم VPS. ويلزم إتاحة TCP/80 لإصدار شهادة HTTPS وTCP/443 لاتصالات البروكسي.

> [!IMPORTANT]
> يجب أن يكون نطاق بروكسي Telegram **غير مستخدم**. لا تستخدم نطاق لوحة 3X-UI أو REALITY أو Vision أو موقع آخر موجود على Nginx.

**إذا كان 3X-UI AUTO NGINX مثبتًا بالفعل**، فافتح قائمته الرئيسية واختر **4 — Telegram Web Proxy Manager**. يمكنك تثبيت TWPM أو تشغيل النسخة المثبتة من هناك.

**للتثبيت المستقل** على VPS يحتوي على Nginx مدعوم، نفّذ بصلاحيات root:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/xPROMSx/telegram-web-proxy-manager/main/install.sh)
```

عند التشغيل اختر **1 — English** أو **2 — Русский**. واجهة المدير متاحة بهاتين اللغتين، ثم تظهر القائمة الرئيسية التالية (الأسماء أدناه كما تظهر في الواجهة الإنجليزية):

- **1 — Install Telegram proxy:** تثبيت جديد أو فحص تثبيت قائم دون إعادة تثبيته.
- **2 — Update Telemt:** البحث عن تحديث لمحرك البروكسي وتثبيته بأمان.
- **3 — Check status:** فحص حالة التشغيل دون تغيير الإعدادات.
- **4 — Check and restart services:** التحقق من الإعدادات وإعادة تشغيل Telemt وإعادة تحميل إعداد Nginx.
- **5 — Show connection link:** عرض رابط إضافة البروكسي إلى Telegram مرة أخرى.
- **6 — Uninstall Telegram proxy:** إزالة التثبيت الذي يديره البرنامج بعد التأكيد.
- **0 — Exit:** الخروج.

للتثبيت لأول مرة، اختر **1 — Install Telegram proxy**. سيطلب المدير بالتتابع:

1. **WEB proxy domain (نطاق البروكسي).** أدخل نطاقًا أو نطاقًا فرعيًا مستقلًا أعددته مسبقًا ولم يُستخدم بعد.
2. **Public IPv4 (عنوان IPv4 العام).** سيحاول المدير اكتشاف عنوان IP لخادم VPS تلقائيًا. قارنه بعنوان IPv4 الصحيح للخادم وسجل DNS A للنطاق. إذا كان صحيحًا، اضغط **Enter** فقط. وإذا فشل الاكتشاف أو ظهر عنوان خاطئ، فأدخل العنوان الصحيح يدويًا.
3. **Use SOCKS5 upstream? [y/N] (استخدام SOCKS5؟)** SOCKS5 بروكسي وسيط اختياري يتيح لخادم VPS الوصول إلى خوادم Telegram. **إذا كان خادمك يصل إلى Telegram مباشرة، فلا تحتاج إلى SOCKS5: اضغط Enter أو اختر N.** إذا تعذّر الاتصال المباشر، فأعدّ بروكسي SOCKS5 صالحًا للعمل *قبل التثبيت*، ثم اختر **Y** وأدخل عنوانه والمنفذ. **لا تعرف ما هو SOCKS5؟ اختر N.**

بعد التثبيت، يجهّز المدير HTTPS وموقع التمويه ويعرض رابط `tg://webproxy?...` جاهزًا لإضافة البروكسي إلى Telegram.

للإدارة لاحقًا، شغّل:

```bash
telegram-web-proxy-manager
```

> [!CAUTION]
> يحتوي رابط الاتصال بـ Telegram على مفتاح وصول خاص إلى البروكسي. لا تنشره أو تشاركه مع أشخاص آخرين.

## 🌐 مواقع التمويه وNginx

**موقع متكامل بدلًا من صفحة افتراضية بسيطة.** ينشئ TWPM تلقائيًا أحد التصاميم الأصلية الثلاثة عند التثبيت الجديد:

- **Botanical Journal** — مجلة عن النباتات.
- **Night Sky Guide** — دليل للسماء الليلية.
- **Home Kitchen** — موقع عن الطبخ المنزلي.

يحتوي كل تصميم على **11 ملفًا محليًا** تشمل عدة صفحات وتنسيقات ورسومات. يتوافق الموقع مع الهواتف، ولا يحتاج إلى موارد خارجية، ويحصل على مظهر مخصّص لكل تثبيت. يبقى التصميم كما هو أثناء التحديثات والصيانة؛ ولا تُستبدل مواقع التثبيتات القديمة.

**يعمل الموقع والبروكسي عبر Nginx المثبت مسبقًا.** لا حاجة إلى Docker أو خادم ويب إضافي.

## 🤝 التكامل مع 3X-UI AUTO NGINX

**مشروعان مستقلان وبنية متوافقة.** يتولى [3X-UI AUTO NGINX](https://github.com/xPROMSx/3x-ui-auto-nginx) تثبيت 3X-UI/Xray وإدارتهما وإعداد Nginx المشترك. ويضيف **Telegram Web Proxy Manager** بروكسي Telegram WEB مستقلًا باستخدام توجيه Nginx المدعوم ونطاق خاص به.

- **ترتيب التثبيت الموصى به:** ثبّت 3X-UI AUTO NGINX أولًا، ثم TWPM. المشروع الأول يثبّت Nginx، أما TWPM فلا يثبّته.
- **مشاركة TCP/443:** يتيح توجيه SNI تشغيل الخدمات على VPS واحد دون استبدال مسارات 3X-UI الموجودة.
- **صيانة مستقلة:** يدير TWPM خدمة Telemt والموقع والشهادات الخاصة به، دون الاستحواذ على إعدادات 3X-UI أو بياناته.
- **التوافق مع Backup v3:** يتعرف الإصدار الحالي من 3X-UI AUTO NGINX على إعدادات TWPM القياسية. لكن نسخة 3X-UI الاحتياطية **لا تغني عن نسخ بيانات Telemt نفسها احتياطيًا**.

**تُدعم إعدادات Nginx الأخرى** إذا كانت مطابقة لأنماط stream/SNI المعروفة لدى TWPM، بما فيها بعض الإعدادات ذات ملفات `include` المنفصلة. لا يعيد المدير تهيئة إعدادات Nginx التعسفية؛ بل يرفض بأمان الإعدادات غير المدعومة أو المتعارضة. [المتطلبات التقنية](docs/OPERATIONS.md#nginx-requirements).

> [!IMPORTANT]
> يدعم TWPM نظامي **Ubuntu 24.04 و26.04**. دعم Debian في 3X-UI AUTO NGINX لا يعني أن Telegram Web Proxy Manager يدعم Debian.

## 🔄 التحديثات والصيانة

عند التثبيت لأول مرة، يثبّت المدير إصدارًا موثوقًا منه من Telemt. تبحث **Universal Update** بصورة مستقلة عن أحدث إصدار رسمي مستقر ومتوافق وتتحقق منه قبل تفعيله. وعند فشل التحديث، تتوفر آلية للعودة إلى الإصدار السابق العامل مع الحفاظ على الحالة والبيانات.

تحديث **TWPM نفسه** وتحديث **Telemt** عمليتان منفصلتان. لا تعيد الصيانة المعتادة إنشاء الموقع أو ضبط المفاتيح السرية أو نقل التثبيتات القديمة إلى إعداد جديد دون موافقة.

يمكن فحص الحالة من القائمة، وتتوفر وظيفة إصلاح للتثبيتات المدعومة عند الحاجة. لا تؤثر الإزالة إلا على العناصر التي ثبت أنها تابعة للمدير، ويتطلب حذف الشهادات تأكيدًا منفصلًا.

## ⚙️ المتطلبات والاختبارات

- **النظام:** Ubuntu 24.04 / 26.04، ومعمارية x86_64 أو ARM64، وصلاحيات root وخدمة systemd.
- **الشبكة:** نطاق أو نطاق فرعي مستقل، وسجل DNS A صحيح، وإتاحة منافذ TCP المطلوبة.
- **Nginx:** إعداد stream/SNI مدعوم وموجود مسبقًا. لا يثبّت المدير Nginx أو 3X-UI أو Xray ولا يغيّر قواعد جدار الحماية.
- **Telemt:** يثبّته TWPM؛ ويستخدم التثبيت الجديد الإصدار الأساسي الموثوق **3.5.16**، بينما تعمل Universal Update بصورة مستقلة.

يخضع المشروع لاختبارات تلقائية وتكاملية على إصدارات Ubuntu المدعومة، بما فيها اختبارات فعلية لـ Nginx وTelemt. تتطلب إعدادات Nginx غير القياسية فحص توافق مستقلًا. [نطاق الاختبارات وحدودها](docs/CI-COVERAGE.md).
