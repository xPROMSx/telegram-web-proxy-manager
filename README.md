**Telegram Web Proxy Manager (TWPM)** — бесплатный менеджер для установки и обслуживания собственного Telegram WEB-прокси на VPS. В основе лежит [Telemt](https://github.com/telemt/telemt), а HTTPS, маршрутизация по домену и сайт-прикрытие работают через Nginx. Менеджер сам настраивает необходимые компоненты, получает сертификат Let's Encrypt и выдаёт готовую ссылку для Telegram.

**Это больше, чем установка Telemt:** каждый новый сервер получает оригинальный многостраничный сайт с персонализированным оформлением. Вместо дополнительного веб-сервера используется уже работающий Nginx; прокси, сертификаты и сайт обслуживаются как единая управляемая установка.

TWPM и [**3X-UI AUTO NGINX**](https://github.com/xPROMSx/3x-ui-auto-nginx) — два проекта xPROMSx, развиваемые с учётом совместной работы. Они могут использовать один VPS и общий Nginx, сохраняя независимое управление своими настройками, сертификатами и службами. **TWPM также работает с другими поддерживаемыми конфигурациями Nginx** — устанавливать 3X-UI необязательно.

## 🚀 Быстрый старт

Вам потребуются **VPS с Ubuntu 24.04 или 26.04**, доступ **root**, работающий Nginx с поддерживаемой SNI-конфигурацией и **отдельный домен или поддомен**. DNS A-запись должна указывать на публичный IPv4 VPS; для HTTPS-сертификата необходим доступ к TCP/80, а для прокси — к TCP/443.

> [!IMPORTANT]
> Домен Telegram-прокси должен быть **свободным**. Нельзя использовать домен панели 3X-UI, REALITY, Vision или существующего сайта Nginx.

**Если у вас уже установлен 3X-UI AUTO NGINX**, откройте его главное меню и выберите **4 — Telegram Web Proxy Manager**. Оттуда можно установить TWPM или запустить уже установленный менеджер.

**Для самостоятельной установки** на VPS с поддерживаемым Nginx выполните от root:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/xPROMSx/telegram-web-proxy-manager/main/install.sh)
```

Выберите **Русский** или **English**, затем **Установить Telegram-прокси** и следуйте подсказкам. Менеджер установит Telemt, настроит HTTPS и сайт-прикрытие, после чего покажет готовую ссылку вида `tg://webproxy?...` для добавления прокси в Telegram.

Для последующего управления используйте:

```bash
telegram-web-proxy-manager
```

> [!CAUTION]
> Ссылка для Telegram содержит секрет доступа к вашему прокси. Не публикуйте её и не передавайте посторонним.

## 🌐 Сайты-прикрытия и Nginx

**Вместо типовой страницы-заглушки — полноценный сайт.** При новой установке TWPM автоматически создаёт один из трёх оригинальных вариантов:

- **Botanical Journal** — журнал о растениях.
- **Night Sky Guide** — путеводитель по ночному небу.
- **Home Kitchen** — сайт о домашней кухне.

Каждый вариант содержит **11 локальных файлов**: несколько страниц, стили и иллюстрации. Сайт адаптирован для мобильных устройств, не требует внешних ресурсов и создаётся с индивидуальным оформлением. Выбранный вариант сохраняется при обновлении и обслуживании; существующие сайты прежних установок не заменяются.

**Сайт и прокси работают через уже установленный Nginx.** Для этого не нужны Docker или дополнительный веб-сервер.

## 🤝 Совместная работа с 3X-UI AUTO NGINX

**Два самостоятельных проекта — одна совместимая инфраструктура.** [3X-UI AUTO NGINX](https://github.com/xPROMSx/3x-ui-auto-nginx) устанавливает и обслуживает 3X-UI/Xray и общую конфигурацию Nginx. **Telegram Web Proxy Manager** добавляет отдельный Telegram WEB-прокси, используя поддерживаемую маршрутизацию Nginx и собственный домен.

- **Рекомендуемый порядок:** сначала 3X-UI AUTO NGINX, затем TWPM. Первый проект устанавливает Nginx; TWPM не устанавливает его самостоятельно.
- **Совместное использование TCP/443:** маршрутизация по SNI позволяет разместить сервисы на одном VPS без замены существующих маршрутов 3X-UI.
- **Независимое обслуживание:** TWPM управляет своим Telemt, сайтом и сертификатами, не принимая владение конфигурацией и данными 3X-UI.
- **Совместимость с Backup v3:** актуальный 3X-UI AUTO NGINX распознаёт штатные конфигурации TWPM. Но Backup 3X-UI **не заменяет резервное копирование данных самого Telemt**.

**Другие конфигурации Nginx тоже поддерживаются**, если соответствуют известным TWPM схемам stream/SNI, включая определённые варианты с отдельными `include`. Произвольные конфигурации Nginx менеджер не перестраивает: при неизвестной или конфликтующей схеме установка безопасно прекращается. [Технические требования](docs/OPERATIONS.md#nginx-requirements).

> [!IMPORTANT]
> TWPM рассчитан на **Ubuntu 24.04 и 26.04**. Поддержка Debian в 3X-UI AUTO NGINX не означает поддержку Debian в Telegram Web Proxy Manager.

## 🔄 Обновления и обслуживание

Менеджер устанавливает проверенную версию Telemt при первой установке. Функция **Universal Update** отдельно ищет новейший совместимый официальный стабильный выпуск и проверяет его до перехода. При неуспешном обновлении предусмотрено возвращение к предыдущей рабочей версии и сохранение состояния.

Обновление **самого TWPM** и обновление **Telemt** — разные операции. Обычное обслуживание не пересоздаёт сайт, не сбрасывает секреты и не переносит старые установки на новую схему без согласия.

Проверка состояния доступна из меню; при необходимости предусмотрено восстановление поддерживаемой установки. Удаление затрагивает только подтверждённо принадлежащие менеджеру объекты, а удаление сертификатов требует отдельного подтверждения.

## ⚙️ Требования и проверки

- **ОС:** Ubuntu 24.04 / 26.04, x86_64 или ARM64; права root и systemd.
- **Сеть:** собственный домен или поддомен, корректная DNS A-запись и доступные необходимые TCP-порты.
- **Nginx:** существующая поддерживаемая конфигурация stream/SNI. Менеджер не устанавливает Nginx, 3X-UI или Xray и не изменяет системные правила firewall.
- **Telemt:** устанавливается самим TWPM; при новой установке используется проверенная базовая версия **3.5.16**, Universal Update работает отдельно.

Проект проходит автоматические и интеграционные проверки на поддерживаемых версиях Ubuntu, включая реальные Nginx и Telemt. Совместимость с нестандартной конфигурацией Nginx требует отдельной проверки. [Объём и ограничения проверок](docs/CI-COVERAGE.md).
